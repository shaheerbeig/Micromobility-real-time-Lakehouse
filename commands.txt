Manual run workflow (no Airflow)

1) Start infrastructure services (Kafka, Zookeeper, Spark Bronze writer, Dashboard):

docker compose up -d

2) Start generator in a separate terminal:

cd data_generation
python generator.py

3) Check messages in Kafka topic:

docker exec mmd-kafka kafka-run-class kafka.tools.GetOffsetShell --broker-list localhost:9092 --topic ride_events --time -1

4) Run Silver manually:

docker exec -it mmd-spark /opt/spark/bin/spark-submit `
  --conf spark.jars.ivy=/tmp/.ivy2 `
  --packages org.apache.spark:spark-sql-kafka-0-10_2.12:3.5.0,io.delta:delta-spark_2.12:3.2.0 `
  --conf spark.sql.extensions=io.delta.sql.DeltaSparkSessionExtension `
  --conf spark.sql.catalog.spark_catalog=org.apache.spark.sql.delta.catalog.DeltaCatalog `
  /opt/spark_streaming/silver_writer.py

5) Run Gold manually:

docker exec -it mmd-spark /opt/spark/bin/spark-submit `

  --packages io.delta:delta-spark_2.12:3.2.0 `

6) Run Mart manually:
